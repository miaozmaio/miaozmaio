## 🧭 我的工作方式

- **不向候选人收费**，简历只在获得你同意后递交给具体岗位
- **信息保密**：聊过的内容不群发、不转卖、不外流
- **说真话**：不合适直接讲，不吊着；合适会告诉你流程、面试官背景、大致时间线
- **岗位必须可追溯**：每条岗位都附来源链接，薪资写实；不符合规则的岗位在仓库里会被自动拦下
